# Code Review Findings

| ID   | Severity | Finding                                                                                                                                            | Evidence                                                                            | Recommendation                                                                                                                               |
| ---- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| F-01 | High     | Conflict detection endpoint is unauthenticated (no API key check), exposing costly LLM calls.                                                      | llm/main.py                                                                         | Add API key verification (same as other endpoints) and reject missing/invalid keys.                                                          |
| F-02 | High     | Conflict detection in backend uses LLM_API_URL, but Docker/env use LLM_SERVICE_URL, so the service falls back to localhost inside containers.      | backend/app/Services/ConflictDetectionService.php; backend/.env; docker-compose.yml | Standardize on LLM_SERVICE_URL (or config-based lookup) to ensure container-to-container routing works.                                      |
| F-03 | Medium   | HDBSCAN is always used and noise clusters are skipped, which can drop conflicts when requirement count is small or all points are marked as noise. | llm/domain_agnostic_conflict_detector.py; llm/main.py                               | Add a small-N fast path (pairwise LLM check or cosine-threshold clustering) before HDBSCAN to avoid false negatives and improve performance. |
| F-04 | Medium   | Postgres volume mounts to /var/lib/postgresql (not /var/lib/postgresql/data), risking data loss on container recreation.                           | docker-compose.yml                                                                  | Mount to /var/lib/postgresql/data per official Postgres image expectations.                                                                  |
| F-05 | Medium   | LLM .env uses Windows-style backslashes and spaces around keys (for example, RAG_ENABLED = "true"), which breaks env parsing in Docker/Linux.      | llm/.env                                                                            | Normalize to KEY=value with no extra spaces; use POSIX paths in containers.                                                                  |
| F-06 | High     | A real API key is committed in repo config, which is a security leak.                                                                              | llm/.env                                                                            | Remove secrets from repo, rotate the key, and load from secure secret storage or local untracked env.                                        |
