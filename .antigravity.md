# Project Rules for LLM4Reqs

## Stack
- Frontend: React
- Backend: Laravel
- Realtime: Reverb
- Database: PostgreSQL
- LLM: FastAPI
- Deployment: Docker Compose

## Coding Rules
- Never rewrite entire files unless explicitly requested.
- Prefer minimal diffs.
- Do not modify docker-compose.yml unless required.
- Always preserve environment variables.

## After Code Changes
- Run: docker compose up -d --build
- Run: php artisan migrate if DB schema changed
- Run: npx playwright test

## Testing
- Prefer end-to-end tests over unit tests.
- Validate WebSocket events when modifying realtime logic.
- Validate LLM responses through API endpoint.

## Safety
- Never delete migrations.
- Never drop database without explicit instruction.
